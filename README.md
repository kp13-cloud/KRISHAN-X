# KRISHAN-X

**KRISHAN-X** is a customized distribution based on the open-source
[DarkFly-Tool](https://github.com/Ranginang67/DarkFly-Tool).

The original project, authorship, and applicable license/attribution are
retained. This repository contains customization and branding changes made
for the KRISHAN-X distribution.

## Features

- Terminal-based security-tools launcher
- Organized tool categories
- Termux-oriented project structure
- Customized KRISHAN-X branding
- Original upstream attribution retained
